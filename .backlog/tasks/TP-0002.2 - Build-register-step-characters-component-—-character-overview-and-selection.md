## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Step 2 of the registration wizard. Players see all their own characters, with a badge or indicator showing which past events each character was used in (via Event_Participants → Character_Versions). They can either select an existing character to bring to the chosen event, or choose to create a new one (advancing to step 3).

Depends on the selected event from step 1 so the component can mark characters already registered for that event as unavailable.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 All characters owned by the logged-in user are listed
- [ ] #2 Each character card shows the event(s) it was previously used in
- [ ] #3 Characters already registered for the currently selected event are shown as unavailable
- [ ] #4 Player can select an existing character to proceed to the confirmation step
- [ ] #5 A 'Create new character' option advances the wizard to step 3
- [ ] #6 Selected character ID is passed back to the parent wizard
<!-- AC:END -->
