## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Step 3 of the registration wizard (only reached when creating a new character). This is a webshop-style builder where the player:
1. Fills in the character's background (name, backstory, etc.)
2. Spends a creation budget on skills (from Skill_Groups / Skills), items (Items table), and implants (Implants table)

The database already has a creation budget column on Characters. The UI should show remaining budget in real time as the player shops. Skill costs, item costs, and implant costs need to be defined (either pulled from the DB or configured as constants — decide at implementation time).

When complete, the new character draft is passed back to the wizard; it is only persisted when the player confirms in step 4.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Character name and background text fields are present and validated (name required)
- [ ] #2 Available skills, items, and implants are loaded from the API and displayed in browsable sections
- [ ] #3 Each purchasable item shows its cost and a buy/remove toggle
- [ ] #4 Remaining budget is displayed and updates in real time as selections change
- [ ] #5 Player cannot spend more than the creation budget (over-budget purchases are blocked)
- [ ] #6 The assembled character draft (name, background, selected skills/items/implants) is passed back to the parent wizard
- [ ] #7 Navigating back to this step from step 4 restores the draft without resetting it
<!-- AC:END -->
