## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Step 4 (final step) of the registration wizard. Shows a summary of the selected event and character, then collects any additional logistics info from the player before submitting. On confirm, the wizard persists the new character (if created in step 3) and writes the Event_Participants row.

Logistics fields include at minimum: dietary requirements (vegetarian, vegan, gluten-free, other + free text). Additional fields can be added here as the game organisation defines them.
