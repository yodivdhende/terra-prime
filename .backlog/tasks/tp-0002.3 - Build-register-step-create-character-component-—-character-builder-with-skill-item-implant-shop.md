## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Step 3 of the registration wizard (when a character-version is selected in step 2 it should be used to display the current settings). This is a webshop-style builder where the player:

1. Fills in the character's name
2. Spends a creation budget on skills (from Skill_Groups / Skills), items (Items table), and implants (Implants table)

The database already has a creation budget column on Characters. The UI should show remaining budget in real time as the player shops. Skill costs, item costs, and implant costs need to be defined (pulled from the DB).

When complete, the new character draft is passed back to the wizard; it is only persisted when the player confirms in step 4.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Character name are present and validated (name required)
- [x] #2 Available skills, items, and implants are loaded from the API and displayed in browsable sections
- [x] #3 Each purchasable item shows its cost and a buy/remove toggle
- [x] #4 Remaining budget is displayed and updates in real time as selections change
- [x] #5 Player cannot spend more than the creation budget (over-budget purchases are blocked)
- [x] #6 The assembled character draft (name, selected skills/items/implants) is passed back to the parent wizard
- [x] #7 Navigating back to this step from step 4 restores the draft without resetting it
<!-- AC:END -->
