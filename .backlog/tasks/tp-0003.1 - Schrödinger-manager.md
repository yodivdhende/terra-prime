## Description

Create `site/src/lib/codex/managers/schrodinger-manager.svelte.ts` — a Svelte 5 singleton manager for the Schrödinger helper character.

## Implementation Notes

- Export singleton `SCHRODINGER_MANAGER` using the rune-based factory pattern (see other managers in `site/src/lib/codex/managers/`)
- State:
  - `$state visible: boolean`
  - `$state message: string`
  - `$state mode: 'idle' | 'registration' | 'notification'`
- Methods:
  - `show(message: string, mode?: 'idle' | 'registration' | 'notification')` — sets visible + message
  - `dismiss()` — sets visible to false
  - `setRegistrationStep(step: number)` — maps step index to canned message and calls show():
    - 0 → "Pick an event you'd like to attend!"
    - 1 → "Choose or create your character."
    - 2 → "Fill in your character's details."
    - 3 → "All set — confirm your registration!"
