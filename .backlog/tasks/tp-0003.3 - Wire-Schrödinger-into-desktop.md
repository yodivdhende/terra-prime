## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Mount `<Schrodinger />` in the desktop layout and trigger the initial greeting notification on page load.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 `<Schrodinger />` is mounted once in `desktop.svelte`
- [ ] #2 Opening `/codex` shows Schrödinger with a greeting after ~1.5 seconds
- [ ] #3 The greeting does not interrupt or override an already-visible registration hint
<!-- AC:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
### `site/src/lib/codex/components/desktop.svelte`
- Import and render `<Schrodinger />` after the windows layer (`<DesktopWindows />`) but before any effects overlays

### `site/src/routes/codex/+page.svelte`
- In `onMount`, after a ~1500ms delay, call `SCHRODINGER_MANAGER.show(greeting, 'notification')` with a welcome/announcement message
- Example greeting: `"Welcome to the Codex! Check out the latest events or register your character."`
- Only show the greeting if `SCHRODINGER_MANAGER` is not already visible (avoid overriding a registration hint)
<!-- SECTION:NOTES:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Mounted <Schrodinger /> in desktop.svelte after DesktopWindows. Added 1500ms delayed greeting in +page.svelte onMount, guarded against overriding an already-visible hint.
