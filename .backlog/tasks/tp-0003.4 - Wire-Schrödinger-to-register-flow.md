## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Integrate `SCHRODINGER_MANAGER` into the registration window so Schrödinger provides step-by-step guidance as the user moves through the 4-step wizard.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Opening the register window immediately shows a Schrödinger hint for step 0
- [ ] #2 Advancing each step updates the speech bubble to the corresponding message
- [ ] #3 Completing registration shows a congratulatory message before Schrödinger dismisses
<!-- AC:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
### `site/src/lib/codex/components/register-window.svelte`
- Import `SCHRODINGER_MANAGER` from the manager
- Add a `$effect` that watches `REGISTER_MANAGER.currentStep` and calls `SCHRODINGER_MANAGER.setRegistrationStep(step)` whenever the step changes
- On component mount (or when the window opens), call `SCHRODINGER_MANAGER.setRegistrationStep(REGISTER_MANAGER.currentStep)` to show the hint for the current step immediately
- When the registration is complete (step reaches the end and is submitted), call `SCHRODINGER_MANAGER.show("You're registered! See you at the event.", 'idle')` then dismiss after a few seconds

The `window` prop provides the `CodexWindow` whose `state` can be watched if needed to detect open/close.
<!-- SECTION:NOTES:END -->
