## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
register-step-create-character.svelte hardcodes the shop layout (200px nav + scroll shop pane), catalog fetching, budget bookkeeping, and the activeStep router that switches between CharacterEditor / ShopSkills / ShopItems / ShopImplants. The admin editor needs the same controls, so this layout has to come out into its own component (e.g. site/src/lib/codex/components/character-version-shop.svelte). The new component should accept a bindable Character + CharacterVersionFull, the three catalogs (or a flag to fetch them itself), and an optional budget. It must NOT depend on RegisterManager.
<!-- SECTION:DESCRIPTION:END -->
