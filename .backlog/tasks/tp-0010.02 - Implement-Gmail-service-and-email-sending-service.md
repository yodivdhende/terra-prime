## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Add server-side email infrastructure.

Files to create:
- src/lib/services/google-gmail-service.ts — mirrors google-drive-service.ts. JWT auth with VITE_GOOGLE_CLIENT_EMAIL, VITE_GOOGLE_PRIVATE_KEY, scope https://www.googleapis.com/auth/gmail.send, and subject = VITE_GOOGLE_EMAIL_SUBJECT (4th arg of google.auth.JWT). Public method: sendMail({to, subject, html}) builds RFC 2822 MIME, base64url-encodes, calls gmail.users.messages.send({userId:'me', requestBody:{raw}}).
- src/lib/db/email_template.repo.ts — class singleton like companies.repo.ts. Methods: getByKey, getById, getAll, upsert (insert when id null, update otherwise; returns id), delete. Type EmailTemplate = { id: number|null, key: string, docUrl: string } + isEmailTemplate guard. Helper extractDocId(docUrl) pulls /d/<id>/ segment.
- src/lib/server/email.service.ts — sendTemplated({to, templateKey, link?}): loads template, fetches HTML via googleDriveService.getDocumentHtml(extractDocId(docUrl)), replaces [[LINK]] if link provided (HTML-escape it), looks up subject from a SUBJECTS map (throws on unknown key), calls gmail sendMail.

Env vars to document for operator: VITE_GOOGLE_EMAIL_SUBJECT (workspace user to impersonate).
