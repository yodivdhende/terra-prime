## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Trigger the verification email automatically on register, and add the page users land on from the email link.

Modify src/routes/api/authentication/register/+server.ts:
- After the existing setSessionToken(cookies, token) call (line 23), fire-and-forget:
    verificationService.sendVerificationEmail(userId, email).catch(err => console.error('[register] failed to send verification email:', err));
- Must not block registration on email send failure.

Create src/routes/verify-email/+page.svelte:
- Reads ?token=... from $page.url.searchParams on mount
- Three states: pending / success / error
- onMount → fetch('/api/authentication/verify-email', {method:'POST', body: JSON.stringify({token})})
- On 200: success message + 'Continue' link to /codex
- On non-2xx: render the JSON error message
- Match the existing terminal/codex visual idiom — see register-window.svelte for reference
