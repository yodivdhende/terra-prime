## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Token + service + password update plumbing.

Files to create:
- src/lib/db/password_reset.repo.ts — createToken(userId): uuidv4 + insert with ExpiresAt = NOW() + INTERVAL 24 HOUR; delete prior tokens for the same user first. consumeToken(token): verify exists + not expired, returns userId, deletes token. Both inside a single connection. removeExpired() called at top of createToken. Mirror email_verification.repo.ts.
- src/lib/server/password_reset.service.ts — sendPasswordResetEmail(userId, email): create token + build link `${PUBLIC_BASE_URL}/reset-password?token=${token}`, call email.sendTemplated({to, templateKey:'password_reset', link}). resetPasswordWithToken(token, newPassword): consumeToken to get userId, then call authenticationRepo.updatePassword(userId, newPassword).

Files to modify:
- src/lib/db/authentication.repo.ts — add updatePassword(userId, newPlain): bcrypt.hash + UPDATE Users SET Password = ? WHERE Id = ?.
- src/lib/server/email.service.ts — add 'password_reset': 'Reset your Terra Prime password' to SUBJECTS.
- src/lib/components/email-template-form.svelte — add password_reset to KNOWN_SUBJECTS so the admin template-form shows the hardcoded subject hint.
