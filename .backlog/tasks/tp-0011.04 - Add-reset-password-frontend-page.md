Create src/routes/reset-password/+page.svelte. Mirror /verify-email (src/routes/verify-email/+page.svelte) UI/styling.

Behavior:
- Read token from page.url.searchParams.
- Initial state: missing token → 'invalid link' error.
- Form: two password inputs (password + confirm). Submit POSTs to /api/authentication/reset-password with {token, password}.
- Client-side validation: passwords match; passwords non-empty.
- States: pending | success | error. On success show 'your password has been reset' and link back to /codex.
