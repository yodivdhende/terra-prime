## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Frontend integration in the codex desktop windows.

src/lib/codex/components/login-window.svelte:
- Extend the existing mode state ('login' | 'register') to also allow 'forgot'.
- Add a 'Forgot password?' link under the password field that switches mode to 'forgot'.
- 'forgot' form: single email input + submit. POSTs to /api/authentication/forgot-password. On success show 'if that email exists, a reset link was sent' (and a 'back to login' button). Form should NOT use enhance since it's calling the API directly with fetch.
- Reuse the existing styling.

src/lib/codex/components/logout-window.svelte:
- Add a 'Reset password' button alongside Logout. Onclick fetches /api/authentication/forgot-password with the current user's email (CREDENTIAL_MANAGER.credentials).
- Inline states: idle | sending | sent | error. Show a small confirmation line on success.
- Important: the credential manager currently stores name/id but not email. If email is unavailable, use the new /api/my/user endpoint (GET) to fetch user.email at click time, or have the forgot-password endpoint accept an authenticated 'reset me' variant. Simpler: call GET /api/my/user to read the email, then POST /api/authentication/forgot-password with it.
<!-- SECTION:DESCRIPTION:END -->
