## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
On /manage/events/[id]/discounts, today only event participants can have discounts edited. Add an 'add' button that opens a side panel with a character search; selecting a character adds them to the discount list for the event so per-character item/implant/skill discounts can be configured for them. The panel should search across all characters (not just event participants).
<!-- SECTION:DESCRIPTION:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Rewrote /manage/events/[id]/discounts to display only characters with discounts (initialized from the event's existing discount records) and added a slide-in side panel triggered by the new '+ add character' button. The panel has a search input that filters all characters (loaded via /api/characters) by name or owner; clicking a result adds the character to the discount map with empty item/implant/skill rows. Replaced the participants-based loop and dropped the participants fetch from the page server loader.
