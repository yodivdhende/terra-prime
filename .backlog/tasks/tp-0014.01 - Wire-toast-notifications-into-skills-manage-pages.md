## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Add TOAST_MANAGER feedback to all save and delete handlers in the skills section of the manage interface. Replace the existing `//TODO make error component` placeholders with proper error toasts.

### Files to update
- `src/routes/manage/skills/new/+page.svelte` — `save()`
- `src/routes/manage/skills/[id]/+page.svelte` — `save()`, `remove()`
- `src/routes/manage/skills/groups/new/+page.svelte` — `save()`
- `src/routes/manage/skills/groups/[id]/+page.svelte` — `save()`, `remove()`

### Toast pattern
- Successful save → `TOAST_MANAGER.success('Skill saved')` (or 'Skill group saved')
- Successful delete → `TOAST_MANAGER.success('Skill deleted')`
- Non-OK response or thrown error → `TOAST_MANAGER.error(...)`

Import path: `$lib/managers/toast-manager.svelte`. `<Toast />` is already mounted in the manage layout — do not re-mount.
