Add TOAST_MANAGER feedback to all save and delete handlers in the events section, including the budget sub-page. Replace the existing `//TODO make error component` placeholders with proper error toasts.

- Successful save → `TOAST_MANAGER.success('Event saved')` / `'Budget updated'`
