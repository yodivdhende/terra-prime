## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Add TOAST_MANAGER feedback to all save and delete handlers in the companies section, including the discounts sub-form on the edit page.

### Files to update
- `src/routes/manage/companies/new/+page.svelte` — `save()`
- `src/routes/manage/companies/[id]/+page.svelte` — `saveCompany()`, `removeCompany()`, `saveDiscounts()`

### Toast pattern
- Successful save → `TOAST_MANAGER.success('Company saved')` / `'Discounts updated'`
- Successful delete → `TOAST_MANAGER.success('Company deleted')`
- Non-OK response or thrown error → `TOAST_MANAGER.error(...)`

Import path: `$lib/managers/toast-manager.svelte`. `<Toast />` is already mounted in the manage layout — do not re-mount.
