## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Add a nullable FormId column to the Events table and surface it through the event repo, API, and admin edit page so an admin can attach a Google Form to an event.

Files:
- New migration under `site/db/migrations/` (next sequential number) adding `FormId VARCHAR(128) NULL` to `Events`.
- `site/src/lib/db/event.repo.ts` — add `formId?: string | null` to `LarpEvent` and `StringLarpEvent`, include in all SELECT lists and the INSERT/UPDATE statements, relax `isLarpEvent` / `isStringLarpEvent` to tolerate the optional field.
- `site/src/lib/components/event-form.svelte` — add a 'Google Form ID' text input bound to `event.formId`. Accept either a full Google Forms URL or a raw ID and parse client-side.
- `site/src/routes/api/CLAUDE.md` — update the Events table row to mention the new field.

Store the bare form ID (the `forms/d/<id>` segment), not the URL — the existing `GoogleFormService.getForm()` takes a raw ID.
