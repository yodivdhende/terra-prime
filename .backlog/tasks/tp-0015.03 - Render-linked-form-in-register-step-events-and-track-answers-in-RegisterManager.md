## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Connect the event's linked Google Form to the registration wizard's events step. Store the form schema and answers in RegisterManager so they survive back/forward navigation, and gate the Next button on required-question completion.

Files:
- `site/src/lib/codex/managers/register-manager.svelte.ts`
  - Add state: `form: GoogleForm | null`, `formAnswers: Record<string, string | string[]>`, `formLoading: boolean`, `formError: boolean`.
  - Add derived `selectedFormId` from `selectedEvent?.formId`.
  - Add methods `setAnswer(qid, value)`, `toggleCheckbox(qid, option)`, `resetForm()`.
  - When `selectEvent` is called, fetch `/api/forms/{formId}` and populate `form` (or clear if no formId).
  - Tighten `canAdvance` for step 0: `selectedEventId !== null` AND (no `selectedFormId` OR `form` is loaded and every required question has a non-empty answer).
  - Clear all form state from `reset()`.
- `site/src/lib/codex/components/register-step-events.svelte`
  - After the existing event row, when `REGISTER_MANAGER.form` is loaded, render `<FormFields form={…} answers={…} setAnswer={…} toggleCheckbox={…} currentSection={0} />`.
  - Render all items flat (no in-step section pagination — wizard's own back/next is the navigation).
  - Show loading and error states matching the existing minimal style.

Notes:
- For multi-section Google Forms, flatten all sections into a single scroll on this step.
- `events: StringLarpEvent[]` round-trips the new `formId` field once TP-0015.01 is merged.
<!-- SECTION:DESCRIPTION:END -->
