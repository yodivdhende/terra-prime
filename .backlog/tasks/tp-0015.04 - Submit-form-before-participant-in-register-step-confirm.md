## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Wire the Google Form submission into the final confirm step. The form must be submitted first; only on success do we save the participant. On failure, the participant is not saved and the user gets a fallback link to the form's responder URL.

Files:
- `site/src/lib/codex/components/register-step-confirm.svelte`
  - In `confirm()`, before the existing `PUT /api/my/events/{eventId}/participants` call:
    - If `REGISTER_MANAGER.selectedFormId` is non-null, POST `REGISTER_MANAGER.formAnswers` to `/api/forms/{formId}/submit`.
    - If the response is HTTP not-ok, or the JSON body's `ok` is `false`, set an error and return without calling the participants endpoint.
  - On submit-error, render a fallback message with the form's `responderUri` (same shape as `form-window.svelte` lines 313–322 — error message plus a link the user can open to fill out the form manually on Google's site).
<!-- SECTION:DESCRIPTION:END -->
