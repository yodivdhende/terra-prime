## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Add a `SheetId VARCHAR(128) NULL` column to the Events table next to FormId, expose it on the LarpEvent repo, and add a focused `setSheetId(eventId, sheetId)` helper for the admin-save path to use without rewriting every field.

Files:
- `site/db/migrations/0008_event_sheetid.sql` (new) — `ALTER TABLE Events ADD COLUMN SheetId VARCHAR(128) NULL DEFAULT NULL`
- `site/src/lib/db/event.repo.ts`
  - Add `sheetId?: string | null` to `LarpEvent`
  - Add `SheetId as sheetId` to SELECT lists in `getAll`, `getWithId`, `getWithStatus`
  - Include `SheetId` in INSERT/UPDATE in `create` and `edit`
  - Add `setSheetId(eventId: number, sheetId: string)` method
<!-- SECTION:DESCRIPTION:END -->
