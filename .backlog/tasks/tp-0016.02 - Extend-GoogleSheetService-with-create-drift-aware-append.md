## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Add the methods needed to create a per-event response spreadsheet in the workspace Drive folder and append rows that respect schema drift by adding a new tab when the form's questions change.

Files:
- `site/src/lib/services/google-sheet-service.ts`
  - Widen `SCOPES` to include `https://www.googleapis.com/auth/drive.file` alongside `spreadsheets`
  - Add `private getDrive()` (mirrors `getSheets()` but for `google.drive({ version: 'v3', auth })`)
  - Add `public async createResponseSpreadsheet(name, parentFolderId, headers): Promise<string>`
    - Drive `files.create` with `mimeType: 'application/vnd.google-apps.spreadsheet'` and `parents: [parentFolderId]`
    - Then `spreadsheets.values.update` to write headers to `Sheet1!A1` (`valueInputOption: 'RAW'`)
    - Returns the new spreadsheet ID
  - Add `public async appendResponseRow(spreadsheetId, headers, row): Promise<void>`
    1. `spreadsheets.get({ fields: 'sheets.properties' })` to list tabs
    2. Pick the most recently added tab (highest index)
    3. Read row 1 via `values.get({ range: \`'\${title}'!1:1\` })`
    4. If row 1 equals headers → `values.append` to that tab
    5. Else → `spreadsheets.batchUpdate({ requests: [{ addSheet: { properties: { title: \`Responses \${ISO timestamp}\` } } }] })`, write headers to row 1 of the new tab, append the row there

Existing playtest methods stay untouched.
