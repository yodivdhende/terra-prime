## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Add the authenticated submit endpoint that writes a single registration row to the event's linked spreadsheet, including the user's id/name/email plus their form answers in column order. Keeps a lazy create fallback in case the admin-save eager create failed.

Files:
- `site/src/routes/api/my/events/[eventId]/form-submit/+server.ts` (new)
  - POST handler:
    1. `const { userId } = await authGuardForUser(getSessionToken(cookies), [UserRole.user])`
    2. `eventId = isNumberOrError(params.eventId)`
    3. `event = await eventRepo.getWithId(eventId)`; throw `NotFoundRequest` if `!event` or `!event.formId`
    4. `user = await userRepo.getById({ id: userId })`
    5. `form = await getGoogleFormService().getForm(event.formId)`
    6. `headers = buildHeaders(form)`
    7. `answers = await request.json()` (`AnswerMap`)
    8. If `!event.sheetId`: call `createResponseSpreadsheet`, `eventRepo.setSheetId`, store on event
    9. Build row: `[new Date().toISOString(), String(userId), user.name, user.email, ...questionsInOrder(form).map(q => formatAnswer(answers[q.questionId]))]` where `formatAnswer` joins arrays with `', '` and coerces null/undefined to `''`
   10. `await getGoogleSheetService().appendResponseRow(event.sheetId, headers, row)`
   11. `return json({ ok: true, status: 200 })`

Reuse `authGuardForUser`, `getSessionToken`, `handleRequest`, `isNumberOrError`, `userRepo.getById`, `eventRepo.getWithId`, `getGoogleFormService().getForm`, `UserRole.user`, plus `buildHeaders`/`questionsInOrder` from `event-sheet.service.ts`.
<!-- SECTION:DESCRIPTION:END -->
