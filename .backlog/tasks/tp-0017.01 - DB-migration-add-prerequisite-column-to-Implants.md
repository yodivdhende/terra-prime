## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Add a nullable self-referencing FK column `Prerequisite` to the `Implants` table so that one implant can require another.

Files:
- `site/db/migrations/0009_implant_prerequisite.sql` (new)
  ```sql
  ALTER TABLE `Implants`
    ADD COLUMN `Prerequisite` int NULL DEFAULT NULL,
    ADD CONSTRAINT `Implants_prerequisite_fk` FOREIGN KEY (`Prerequisite`) REFERENCES `Implants` (`Id`) ON DELETE SET NULL;
  ```
