## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Add a small reactive viewport helper that tells the codex whether to render the desktop or the phone layout. This is the single source of truth consumed by the codex root and downstream mobile components.

Files:
- New `site/src/lib/codex/managers/viewport-manager.svelte.ts` — a rune-based singleton (matching the `*.svelte.ts` manager pattern, e.g. `effects-manager.svelte.ts`) exposing `isMobile` derived from a `window.matchMedia('(max-width: 640px)')` query (~`640px` / `48rem`). Subscribes to the media query `change` event; cleans up on teardown.

Keep it SSR-safe: default `isMobile` to `false` when `window` is undefined and resolve the real value once mounted (in a `$effect` from the root, or guarded inside the manager).
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 `isMobile` flips reactively when the viewport crosses the breakpoint (resize + orientation change)
- [ ] #2 SSR-safe: no reference to `window`/`matchMedia` during server render; sensible default
- [ ] #3 Exposed as a single shared source consumed by the codex root
- [ ] #4 Media-query listener is registered once and cleaned up on teardown
