## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Build the phone home screen: render every codex icon as an app tile, like a smartphone's app grid.

Files:
- New `site/src/lib/codex/components/mobile-home.svelte` — iterates `ICON_MANAGER.icons` (the same `$derived` list that drives the desktop) and renders each as an app tile (Lucide icon + label) in an evenly spaced, responsive multi-column grid. Reuse the existing type → Lucide icon mapping from `desktop-icons.svelte` (`file`/`doc`/`pdf` → `File`, `dir` → `Folder`, `image` → `Image`, `settings` → `Settings`, `playtest` → `ClipboardPen`, `login` → `UserRound`). Ignore the desktop `left`/`right` side split — on mobile all icons share one grid.
- Tap handler: `WINDOW_MANAGER.openWindow(windowId)` then `WINDOW_MANAGER.focusWindow(windowId)`.

Styling: use theme tokens from `theme.css` (phosphor green, mono font, glow on press); touch targets ≥ 44px; the grid must wrap responsively with no horizontal overflow on a 360px-wide screen.
<!-- SECTION:DESCRIPTION:END -->
