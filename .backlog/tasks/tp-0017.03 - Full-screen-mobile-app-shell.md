## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Render the active app full-screen, replacing the floating draggable window on mobile.

Files:
- New `site/src/lib/codex/components/mobile-app.svelte` — renders the currently active window full-screen: a top bar showing the window `title` with a **close button in the top-right** that calls `WINDOW_MANAGER.closeWindow(id)` to return to the home screen. The body delegates to the existing `window-content.svelte` (routes `window.type` → the per-type content component) inside a scrollable container. No drag, no resize, no resize handles.
- Add an "active app" selector — a `$derived` in `window-manager.svelte.ts` (or `icon-manager.svelte.ts`) returning the focused open window (the open window with the highest `position.z`), or `null` when none is open. `mobile-home` shows when this is `null`; `mobile-app` shows otherwise.

Reuse the window chrome styling cues from `window.svelte` (header/title/close button using `X` from `@lucide/svelte`) but full-bleed rather than absolutely positioned.
