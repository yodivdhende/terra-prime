## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Update the player-facing implant shop to block purchasing an implant whose prerequisite is not owned, and block removing an implant that another owned implant depends on.

Files:
- `site/src/lib/codex/components/shop-implants.svelte`
  - Add `prerequisite?: number | null` to the `ShopImplant` type
  - Derive `prerequisiteMissing`: `implant.prerequisite != null && !has(implant.prerequisite)`
  - Derive `isPrerequisiteFor`: true when another selected implant lists this implant as its prerequisite
  - Disable buy button when `prerequisiteMissing` (in addition to existing budget check)
  - Disable remove button when `isPrerequisiteFor`
  - Show a "requires: <name>" hint line under the implant name when `prerequisiteMissing` (look up name from `catalog` by ID)
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 An implant with an unowned prerequisite shows "requires: <name>" and has its buy button disabled
- [ ] #2 Once the prerequisite is added to the selection, the dependent implant becomes purchasable
- [ ] #3 Removing an implant that is a prerequisite for another currently selected implant is blocked (button disabled)
- [ ] #4 No visual regression on implants without prerequisites
