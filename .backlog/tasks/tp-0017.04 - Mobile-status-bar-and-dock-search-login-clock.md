## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The desktop taskbar (search, login/user button, status tray with clock) has no mobile equivalent. Adapt its essentials for the phone layout so search and login remain reachable.

Files:
- New `site/src/lib/codex/components/mobile-statusbar.svelte` (and/or a bottom dock) — a compact top status bar showing the clock (reuse the clock logic/markup from `task-icons.svelte`) and a bottom dock or home action that exposes search (reuse `search-bar.svelte`) and the login/user button (reuse the `openUserWindow` logic from `taskbar.svelte`, which opens `login` or `logout` based on `CREDENTIAL_MANAGER.isLogedIn`).
- Respect `FEATURE_MANAGER.loginEnabled` exactly as the taskbar does (hide the login button when disabled).

Keep it themed and touch-friendly; the search input must be usable on small screens (full-width or an expandable search affordance).
