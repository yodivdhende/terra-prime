## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Tie everything together: branch the codex root on the viewport so the desktop UI renders on wide screens and the phone UI renders on narrow screens.

Files:
- `site/src/lib/codex/components/desktop.svelte` (and/or `site/src/routes/codex/+page.svelte`) — read `isMobile` from the viewport manager (TP-0017.01). When false, render the existing desktop (`desktop-icons` + `desktop-windows` + `taskbar`). When true, render `mobile-statusbar` + `mobile-home` + `mobile-app`.
- Keep `<Toast />` mounted exactly once (it currently lives in `desktop.svelte` — do not mount a second copy in the mobile tree).
- Preserve the CRT / scanline / vignette overlays and the backdrop from `+page.svelte` so `EFFECTS_MANAGER` toggles still apply in mobile mode.

Because both layouts read the same `WINDOW_MANAGER` state, switching widths must not lose open windows or auth state.
