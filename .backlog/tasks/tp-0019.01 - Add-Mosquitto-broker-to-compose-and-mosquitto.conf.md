## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Add an Eclipse Mosquitto broker so devices (MQTT/TCP) and the browser (MQTT/WebSocket) can
both connect.

### Files
- **`compose.yml`** — add an `mqtt` service:
  - `image: eclipse-mosquitto:2`, `container_name: terra-prime-mqtt`
  - ports `1883:1883` (MQTT/TCP, CYD) and `9001:9001` (MQTT/WebSocket, browser)
  - mount `./mqtt/mosquitto.conf:/mosquitto/config/mosquitto.conf`
  - make `sveltekit` `depends_on: mqtt`
- **`mqtt/mosquitto.conf`** (new):
  ```
  listener 1883
  protocol mqtt
  listener 9001
  protocol websockets
  allow_anonymous true
  persistence true
  persistence_location /mosquitto/data/
  ```

Anonymous access is fine for local dev; auth/TLS is a follow-up.
