## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Swap the CYD firmware's WebSocket client for an MQTT client (PubSubClient), preserving the
existing screen-routing and link behaviour.

### Files
- **`cyd/platformio.ini`**: remove the `arduinoWebSockets` dep, add `knolleary/PubSubClient@^2.8`,
  add `build_flags = -DMQTT_MAX_PACKET_SIZE=512` (JSON payloads exceed the 256-byte default).
- Rename **`cyd/src/web-socket.cpp` → `cyd/src/mqtt-client.cpp`** and
  **`cyd/src/web-socket.h` → `cyd/src/mqtt-client.h`**:
  - `WiFiClient net; PubSubClient mqtt(net);`
  - `mqttSetup()`: `mqtt.setServer(domain.c_str(), mqttPort); mqtt.setBufferSize(512); mqtt.setCallback(onMessage);`
  - reconnect helper: `mqtt.connect(sessionToken.c_str(), /*will*/ ("terra/status/"+sessionToken).c_str(), 0, true, "")`
    (empty retained LWT). On success: publish retained status (reuse `sendStatus()` body),
    then `mqtt.subscribe(("terra/goto/"+sessionToken).c_str())`.
  - `onMessage(topic, payload, length)`: reuse the existing `handleMessage` JSON parse →
    `goTo.screen` → `UiLoadingSetup()` / `UiLootSetup()` / `UiVirusSetup()`.
  - `sendStatus()`: publish retained to `terra/status/{token}`
    `{sessionToken, connectionType:"CYD", wifiStrength}`.
  - `sendLink(token, status)`: publish to `terra/link` `{origin: sessionToken, linkTarget: token, isLinked: status}`.
  - `mqttLoop()`: if `!mqtt.connected()` reconnect, then `mqtt.loop()`.
  - Header exposes `mqttSetup()`, `mqttLoop()`, `sendLink(String, boolean)`.
- **`cyd/src/main.cpp`**: replace `#include <web-socket.h>` and the `webSocketSetup()` /
  `webSocketLoop()` calls with `mqtt-client.h` / `mqttSetup()` / `mqttLoop()`. `mqttSetup()`
  stays inside the currently-commented network block; `mqttLoop()` goes in `loop()`.
- **`cyd/src/uart-interface.cpp`**: change `#include <web-socket.h>` → `#include <mqtt-client.h>`
  (it still calls `sendLink`).
