## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Rename the device's port config from WebSocket to MQTT and update all docs to describe MQTT
instead of WebSockets.

### Config / globals
- **`cyd/src/globals.h` / `globals.cpp`**: replace `extern int webSocketPort;` / its definition
  with `int mqttPort;` (keep `domain` as the broker host).
- **`cyd/src/sd-reader.cpp`** `readConfig()`: read `mqttPort` from the JSON instead of
  `webSocketPort` and assign to `mqttPort`.

### Docs
- **`cyd/CLAUDE.md`**: update the communication table, the file list (`web-socket.*` →
  `mqtt-client.*`), the boot-sequence step (`webSocketSetup()` → `mqttSetup()`), the runtime
  `config.json` block (`webSocketPort` → `mqttPort`, value `1883`), and the gotchas.
- **`site` docs** (`site/CLAUDE.md` and/or `README.md`): update any WebSocket references for
  the realtime/sessions flow to MQTT, and document `PUBLIC_MQTT_WS_URL` + the broker.
- Update the `config.json` example to use `"mqttPort": 1883`.
